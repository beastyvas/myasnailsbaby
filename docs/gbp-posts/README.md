# Google Business Profile posts

One ready-to-paste post per guide. The guide writer adds a new file here every
time it publishes a guide (docs/SEO_ROUTINE.md, WEEKLY step 7b).

Each file looks like this:

```
**Post:**
<300–600 characters: the question in one line, what the guide covers. No
links in the text (Google strips them), no prices, no stats the guide doesn't
have.>

**Button:** Learn more
**Link:** https://www.myasnailsbaby.com/guides/<slug>
**Photo:** https://www.myasnailsbaby.com/api/og
```

To post: Google Business Profile → Add update → paste the **Post** text →
Add button **Learn more** → paste the **Link** → add the **Photo** → Post.
Rename the file to start with `posted-` afterwards so the next one is obvious.

A real photo of a fresh set beats the logo card every time — swap one in
whenever Mya has one she's happy to share.

Regular posts are one of the few things that keep a Business Profile looking
active, which matters while she builds up in Henderson.
